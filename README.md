# PastryMY Pro (RMY)

## هيكل المشروع
- `index.html`: الهيكل الرئيسي. بيحمّل ملفات CSS وJS بالترتيب.
- `invoice.html` و`maintenance.html`: صفحات مستقلة. لازم تفضل في الجذر لأن `index.html` بيفتح `invoice.html` بمسار نسبي.
- `css/`: ملفات التنسيق. الترقيم يحدد ترتيب التحميل، والترتيب مهم لأن الـ cascade بيعتمد عليه.
- `js/`: ملفات الكود. الترقيم يحدد ترتيب التنفيذ، والترتيب مهم لأن الملفات بتعتمد على بعض.
- `ICONS/`: كل الصور والأيقونات (اللوجو وأيقونات المتصفح والتطبيق).
- `supabase-config.js`: إعدادات الاتصال بـ Supabase.
- `sw.js`: الـ Service Worker. قائمة `SHELL` فيها الملفات اللي بتتخزن للعمل أوفلاين.
- `manifest.webmanifest`: إعدادات التطبيق المثبت (PWA).

## قواعد الصيانة
1. أي ملف CSS أو JS جديد: ضيفه في `index.html` في مكانه الصح، وضيف مساره في `SHELL` في `sw.js`.
2. أي صورة جديدة: حطها في `ICONS/`. ولو بتتستخدم من CSS، المسار يبقى `../ICONS/...`.
3. بعد أي تعديل، زوّد رقم `CACHE` في `sw.js` (مثلاً `rmy-shell-v5`) عشان المستخدمين ياخدوا النسخة الجديدة.
4. ما تغيرش ترتيب الملفات من غير ما تفهم الاعتماد بينها.

## الصيانة والاختبار
- `AUDIT.md`: تقرير الدوال المكررة والملاحظات الحالية. اقرأه قبل أي تنظيف.
- `tools/smoke-test.py`: اختبار سريع يفتح الصفحة ويقارن الأخطاء وعدد العناصر. شغّله قبل وبعد أي تعديل وقارن النتيجتين.
- ملاحظة: `window.toast` في `js/085-ui-notifications-bell.js` بيبان إنه زيادة، لكن شيله بيغيّر الـ DOM. ما تشيلوهوش.

## تسمية ملفات الـ JavaScript
الاسم بيتكون من: `رقم الترتيب` + `المجال` + `الوظيفة`، مثال: `085-ui-notifications-bell.js`.
- الرقم بيحدد ترتيب التحميل، ما تغيرهوش.
- المجالات: `core` (الإقلاع والأساسيات)، `auth` (تسجيل الدخول)، `cloud` (المزامنة والحفظ السحابي)، `ui` (الواجهة)، `menu` (المنيو)، `sales` (المبيعات والسلة)، `invoices` (الفواتير)، `messages` (الرسايل)، `customers` (العملاء)، `parties` (الحفلات)، `inventory` (المخزون)، `recipes` (الوصفات والتكلفة)، `barista` (الباريستا)، `reports` (التقارير)، `admin` (الإدارة والصيانة)، `export` (التصدير).
- ملفات `ui-*` و`admin-*` بتعدل أي شاشة، فلو عايز تغيّر شاشة معينة ابدأ بالمجال بتاعها.

## تسمية ملفات الـ CSS
نفس فكرة الـ JavaScript: `رقم الترتيب` + `المجال` + `الوظيفة`، مثال: `108-ui-notifications-bell.css`.
- الرقم بيحدد ترتيب التحميل، و**الترتيب ده مهم جداً**: أي ملف متأخر بيغلب على اللي قبله في نفس الخاصية. ما تغيرهوش.
- المجالات: `base` (الأساس والـ reset)، `theme` (الألوان والوضع الليلي)، `layout` (ترتيب الشاشات)، `header` و`nav` و`dock` (الشريط العلوي والتبويبات والشريط السفلي)، `menu` و`sales` و`invoices` و`parties` و`barista` و`customers` و`messages` و`reports` و`admin` و`cloud` و`auth` (الشاشات ووظايفها)، `ui` (عناصر واجهة مشتركة)، `print` (الطباعة).
