# Mise · تطبيق كامل من الصفر (نسخة تجريبية على الجهاز)

## الأقسام
- الرئيسية: أرقام الفترة، دفعات الإنتاج، الجاهز للبيع، تنبيهات المخزون.
- الوصفات: مراحل (تحضير، فرن، نار، تبريد/فنش)، وصفات فرعية، تكلفة، هامش، تعديل.
- الإنتاج: بدء دفعات مع فحص الخامات والخصم الذري، وسجل الدفعات.
- المخزون: أرصدة، حد أدنى، توقع النفاد، خامات جديدة.
- المبيعات: فواتير من الجاهز، مدفوع ومتبقي.
- العملاء والحفلات: عملاء، حجوزات بعربون ودفعات، مستحقات.
- التسعير: تكلفة، مقترح، سعر فعلي، هامش محقق.
- التقارير: الربح الإجمالي، المصروفات، المسحوبات، الصافي، أداء كل صنف.
- الفريق: موظفين بأدوار وPIN.
- الإعدادات: نسخة احتياطية JSON واسترجاعها، سجل العمليات، رجوع للبيانات التجريبية.

## الصلاحيات حسب الدور
- مدير: كل الأقسام.
- مطبخ: الرئيسية، الوصفات، الإنتاج، المخزون.
- مبيعات: الرئيسية، المبيعات، العملاء.
- بار: الرئيسية، الإنتاج.

## التشغيل
- الاختبارات: `node tests/core.test.mjs && node tests/logic.test.mjs && node tests/views.smoke.mjs`
- الواجهة: افتح `index.html` من خادم محلي (مثلاً `npx serve`).

## حدود النسخة دي (مهمة)
- البيانات محفوظة **على الجهاز** (localStorage)، مش على السحابة. كل جهاز له بياناته.
- تسجيل الدخول **محلي**: الـ PIN متخزن على الجهاز، ومش آمن للإنتاج.
- مفيش مزامنة مع Supabase، ومفيش `pastry-api`.
- مفيش صلاحيات على السيرفر. كل الفحوصات على المتصفح.

## للإنتاج لازم
1. ربط الكتابة والقراءة بـ `pastry-api` (كود السيرفر مطلوب).
2. التحقق من PIN على السيرفر.
3. صلاحيات الخصم والبيع على السيرفر، مش المتصفح.
4. اختبار على موبايل حقيقي ونسخة تجريبية.
